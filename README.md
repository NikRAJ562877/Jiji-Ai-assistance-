# Learn With Jiji

A simple Flutter app that showcases an AI friend UI.

## Features
- Attractive UI with a large avatar image.
- Search bar that overlaps the bottom of the avatar.
- Response card with bullet points.
- Resource tiles for presentations and videos.
 

## Getting Started

1. **Prerequisites**
   - Flutter SDK (>=3.7.2)
   - Android Studio / Xcode for device emulators

2. **Clone the repository**
```bash
git clone <repo-url>
cd learn_with_jiji
```

3. **Install dependencies**
```bash
flutter pub get
```

4. **Run the app**
```bash
flutter run
```
   - Choose a device/emulator when prompted.

## Project Structure
- `lib/main.dart` – Main UI implementation.
- `assets/jiji_avatar.png` – Placeholder avatar image.
- `pubspec.yaml` – Asset declaration and dependencies.

## Customization
- Update `assets/jiji_avatar.png` with your own image.
- Adjust UI colors and fonts in `ThemeData` inside `JijiApp`.
